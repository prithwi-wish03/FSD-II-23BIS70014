# Experiment 2 — Responsive UI Using Material UI

This project contains:
- Responsive Landing Page
- Dashboard with Navbar, Sidebar & Responsive Cards
- Admin Panel with Light/Dark Theme Switching

## Installation
```
npm install
npm install @mui/material @emotion/react @emotion/styled styled-components
npm run dev
```

## Structure
```
src/
 ├── App.jsx
 ├── main.jsx
 ├── index.css
 └── components/
     ├── LandingPage.jsx
     ├── Dashboard.jsx
     ├── AdminPanel.jsx
```
